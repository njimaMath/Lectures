# PT26w の講義資料の作成・更新

この指示は `PT26w/` とその下の全ディレクトリに適用する。対象は「確率論と統計学 I」の資料であり、特に `classN/resumeNPT26.tex` と `classN/classNPT26.tex` の作成・更新に用いる。`N` は授業回を表す整数である。ユーザーの個別の指定を優先する。

## 参照資料と対象回の確認

| ファイル | 役割 |
| --- | --- |
| `classN/resumeNPT26.tex` | 各回の詳しいレジュメ、演習問題、レポート問題、コラム |
| `classN/classNPT26.tex` | 既存の配布資料。複数回分を含む場合がある |
| `classN/stN.html` | 同じ回のコラムの参照元 |
| `classN/answer_exerciseN.tex` | 存在する場合、その回の演習解答の参照元 |
| `class1/class1PT26.tex` | シラバス、授業計画、第1回の資料 |
| `class2/class2PT26.tex` | `class` 資料の基本スタイルの基準 |
| `class2/resume2PT26.tex` | 詳しいレジュメの基本スタイルの基準 |
| `lectureNote.tex`・`lectureNotes.tex` | 定義、定理、説明、例の参照元 |

- 最初に対象ファイルと参照元を UTF-8 で読み、適用される指示と作業中の変更を確認する。PowerShell では `Get-Content -Encoding utf8` を使う。
- 対象回は本文の見出しで確認する。ファイル名だけで判断しない。例えば [class2PT26.tex](class2/class2PT26.tex) は第2回と第3回を含み、第3回の問題もこのファイルにある。
- [resume3PT26.tex](class3/resume3PT26.tex) は、前回の演習解答やコラムの構成の補助的な参照元とする。
- 既存ファイルが Git の未追跡ファイルでも、ユーザーの作業成果として扱う。変更前の比較に必要なら `tmp/` 以下に一時コピーを置く。
- 変更箇所を依頼された範囲に絞り、既存の本文、問題、コラムを保ちながら更新する。

## 共通の体裁と文章

- `PT26w/` 内の資料は、基本的に `class2/` の [class2PT26.tex](class2/class2PT26.tex) と [resume2PT26.tex](class2/resume2PT26.tex) と同じスタイルにする。`classNPT26.tex` は前者、`resumeNPT26.tex` は後者を基準とし、フォント、文字サイズ、余白、配色、見出し、マクロ、ヘッダー・フッター、段落・数式・箇条書きの間隔をそろえる。授業回、内容、必要なページ数は対象資料に合わせる。ユーザーの個別の指定がある場合は、その指定を優先する。
- 日本語の学部向け講義資料として、読みやすく丁寧に書く。仮定、記号、定義域、区間、端点の扱いを明記する。
- 太字の文章や数式を新たに使わない。見出しは既存の `\sffamily\mdseries` を使う。
- 解答やまとめを含むすべての数式で `\boxed` を使わない。結果は通常の数式として示す。参照資料に既存の使用例があっても、このルールを優先する。
- 証明は番号付きの手順に分割せず、数式とつながりのある文章で書く。演習問題の番号は使用してよい。
- 数式はインラインに `$...$`、独立した表示に `$$...$$` を使う。整列にはその中で `aligned` などを使う。HTML の数式には MathJax を使う。
- A4、10 pt の `bxjsarticle` と、`pdflatex,ja=standard,jafont=ipaex-type1,magstyle=real,scale=1` の設定を踏襲する。
- 本文は原則として `\fontsize{10pt}{13.5pt}\selectfont` とし、左右 22 mm、上 20 mm、下 17 mm の余白を保つ。
- 色は既存の `ink`（`193A5C`）、`accent`（`237D82`）、`soft`（`EAF3F3`）、`muted`（`52616B`）を使う。
- `\handouttitle`、`\topic`、`\keybox`、`\examplelabel`、コラム用の既存マクロを利用する。段落、数式、箇条書きの間隔も既存の設定に合わせる。
- ヘッダーには科目名、内容の種別、配布する授業回を表示する。フッターは現在ページ／総ページ数とし、詳しいレジュメでは `\thepage/\pageref*{lastpage}` を使う。
- 図や表は説明に必要な場合に入れ、記号と本文の対応を明確にする。

## レジュメのページ構成

第2回以降の `resumeNPT26.tex` は、次の順序にする。

1. 1ページ目：第 `N-1` 回の演習問題の解答。
2. 2ページ目から：第 `N` 回のレジュメ本文、定義、定理、例。
3. 当該回の演習問題とレポート問題。
4. 当該回のコラム。

前回の解答は必ず1ページに収め、当該回のレジュメは物理的な2ページ目から始める。以降のページ数は内容に応じて決める。総ページ数を固定しない。

- 解答ページの題名は「第 `N-1` 回 演習問題の解答」とする。ヘッダー右側の授業回は配布回の第 `N` 回とする。
- 解答ページだけヘッダー左側を「前回の演習解答」にする。`\begingroup` で局所化し、解答末尾で `\clearpage`、その後に `\endgroup` を置いて、通常のヘッダーへ戻す。
- 第1回には前回の解答を作らない。シラバスを含む `class1PT26.tex` の構成は、個別の依頼に従う。
- `classNPT26.tex` は既存の収録回と構成を確認して編集する。複数回分を含む資料では、各回の題名とヘッダーを適切に切り替える。前回解答の先頭ページを追加する依頼がある場合は、上記の配置方法を使う。

## 前回の演習解答を書く工程

1. 前回に配布するレジュメの「演習問題」を確認する。前回のレジュメがない場合は、対応する `class` 資料の該当回を確認する。
2. 同じ問題の既存解答があれば、問題文、仮定、番号が一致することを確かめて利用する。第1回は [answer_exercise1.tex](class1/answer_exercise1.tex) が参照できる。
3. 演習番号を対応させ、各問の設定を短く再掲して、結論に至る計算や証明を書く。前回のレポート問題の解答は、依頼された場合に追加する。
4. 計算結果、確率の総和、分布関数の端点、定理の仮定を確認する。有限個の標本を扱う問題は、必要に応じて列挙による計算でも検算する。
5. 解答を先頭に挿入し、元のレジュメ本文以降が保たれていることと、解答が1ページに収まることを確認する。

分布関数の解答では、値域内の式だけでなく、値域の外での値も示す。離散分布を表で示す場合は、整数点以外の値の決め方も説明する。連続モデルでは、事象を標本空間上の区間や集合に書き換えてから確率を求める。

現在の対応例：

- `resume2PT26.tex` の1ページ目は、第1回のサイコロの確率空間と和事象の公式の解答。
- `resume3PT26.tex` の1ページ目は、第2回のサイコロの和・差の絶対値、および区間上の確率変数の分布関数の解答。

## 演習問題・レポート問題を一致させる工程

1. ユーザーが指定した参照ファイルの中で、対象回の開始位置と、二つの問題欄の範囲を特定する。
2. 「全く同じ」という指定では、問題文、問題数、順序、記号、数式、仮定、共通の設定、注意書きをそのまま転記する。AI の利用に関する注意書きも含める。
3. 問題文の書き換えや、問題の追加・削除を独自に行わない。
4. 転記後に参照元と該当ブロックを比較し、一致を確認する。比較のための改行コードの統一はよいが、内容の差を見落とす正規化はしない。
5. 更新した問題と周辺の説明や参照の整合性を確認し、矛盾があれば必要な範囲で修正する。

第3回の問題の参照元は [class2PT26.tex](class2/class2PT26.tex) の第3回部分である。第2回部分の問題を取り違えない。

## コラムを HTML と一致させる工程

1. `classN/stN.html` の記事の題名、本文、見出し、例、まとめを確認する。
2. 内容を合わせる依頼では、それらを同じ順序で TeX のコラムへ反映する。参照元にない別の話題で置き換えない。
3. HTML の見出しは `\columnheading` などに、数式は既存の TeX の記法に対応させる。コラムは改ページして始める。
4. TeX のコラムではシミュレーションについて触れない。設定や観察点の説明への置き換え、操作方法、HTML版への案内も省く。ナビゲーションや操作ボタンも転記しない。
5. 明らかな誤字は最小限整える。数学的な条件や意味を補正した場合は、仕上がりの報告で簡潔に伝える。

例えば [resume3PT26.tex](class3/resume3PT26.tex) のコラムは [st3.html](class3/st3.html) に対応する。

## コンパイルと確認

TeX を変更したら、同じディレクトリにある同名の PDF も更新する。対象ファイルのディレクトリで `pdflatex` を2回実行し、ページ参照と総ページ数を確定する。例えば、リポジトリルートから第3回を更新する場合は次を実行する。

```powershell
Set-Location PT26w/class3
pdflatex -interaction=nonstopmode -halt-on-error -file-line-error resume3PT26.tex
pdflatex -interaction=nonstopmode -halt-on-error -file-line-error resume3PT26.tex
```

`class` 資料を更新した場合は、対象の `classNPT26.tex` を指定して同様にコンパイルする。

- 終了コードとログを確認する。未定義の参照、未定義のコマンド、文字の欠落、本文のはみ出しを解消する。
- PDF をページ画像に変換し、更新ページを目で確認する。前回解答を追加した場合は、少なくとも1ページ目、2ページ目、総ページ数を確認する。
- ページ番号、ヘッダーの切り替え、改ページ、数式、表の幅、文字の重なり、切れ、不要な空白ページを確認する。
- 画像化の一時ファイルはリポジトリルートの `tmp/pdfs/` 以下に置く。例えば次は、リポジトリルートから第3回の先頭2ページを確認するコマンドである。

```powershell
New-Item -ItemType Directory -Force tmp/pdfs | Out-Null
pdftoppm -f 1 -l 2 -r 110 -png PT26w/class3/resume3PT26.pdf tmp/pdfs/resume3-preview
```

- 元の本文を保って先頭1ページを追加する作業では、元の各ページが1ページ後ろに移っていることを確認する。TeX の元の本文を比較し、必要なら PDF の抽出テキストでもページ番号以外の内容が保たれているか確認する。
- 完了時に一時コピー、プレビュー画像、検証用ログを片づける。ユーザーの成果物や既存の作業ファイルは保つ。
- 最後に、変更した TeX と PDF の場所、主な変更、実施した確認を簡潔に報告する。指示書だけの変更では、内容の確認を行い、TeX の再コンパイルは不要である。
